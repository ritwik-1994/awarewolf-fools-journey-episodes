# The Fool's Journey · Episode boards

Storyboards, animatics and review pages for AwareWolf's 44-episode series.

Live site: https://ritwik-1994.github.io/awarewolf-fools-journey-episodes/

## Layout

```
index.html                 Season index
episodes/001/index.html    Latest Episode 1 board (always the current revision)
episodes/001/board-r2.html Archived revision r2
episodes/002/ ...          Added as each episode reaches Level 1
```

Each new revision replaces `episodes/NNN/index.html` and is also saved as `board-rN.html`, so old links keep working.

## Feedback

Reviewers mark each shot Keep, Rework or Discuss and add notes on the board. Notes save in their browser. **Send feedback** opens a pre-filled GitHub issue in this repo; the reviewer clicks **Create**. Each issue carries a readable summary plus a JSON block so revisions can be made from it directly.

Reviewers without a GitHub account use **Copy feedback** and send the text to Ritwik.

Note: this repo is public, so issues are public too.

## Status

Boards are review drafts. Figures are blocking stand-ins, not character art, and nothing here approves generation or release.
